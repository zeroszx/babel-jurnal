Google Gemini (gratis)

Buat kunci API gratis di aistudio.google.com/apikey (cukup login dengan akun Google, tanpa kartu kredit). Kuota gratis dibatasi per menit dan per hari. Di paket gratis, Google dapat memakai data yang dikirim untuk meningkatkan layanannya, jadi hindari mengirim naskah rahasia yang belum terbit.

Model "flash" disarankan: cepat dan kuota gratisnya paling longgar. Model "pro" lebih teliti, tetapi kuota gratisnya jauh lebih kecil.

Claude (Anthropic, berbayar)

Kunci API dari console.anthropic.com. Pemakaian dikenai biaya per token sesuai tarif Anthropic.

Pencarian (OpenAlex)

Pencarian bisa dipakai tanpa pengaturan apa pun. Tanpa kunci API, kuota harian gratis OpenAlex dibagi dengan semua pengguna di jaringan yang sama. Kunci API gratis (kuota sendiri) bisa dibuat di openalex.org/settings/api. Keduanya opsional dan hanya dikirim ke OpenAlex.
